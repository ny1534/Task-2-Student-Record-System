# Task-2 - Student Record Management System

This is a simple Java project for managing student records.

## What I did in this task:
- Created a Student class to store student details (ID, Name, Marks)
- Created StudentManagement class with main menu
- Added features: Add Student, View Students, Search, Delete

## How to Run:
1. javac Student.java StudentManagement.java
2. java StudentManagement
